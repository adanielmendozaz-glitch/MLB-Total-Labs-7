Líneas automáticas · sin captura manual

Por defecto intenta primero el proveedor interno de la app (Netlify Function → ESPN/DraftKings), sin API key y sin CORS. Si no está disponible, intenta ESPN desde el navegador y luego Covers. Después usa la última línea válida guardada. La app sólo utiliza el Total de juego completo; nunca inventa una línea de sportsbook.
Importante: el aprendizaje es calibración estadística, no memoria mágica. Necesita decenas o cientos de juegos liquidados. El sistema limita la confianza cuando faltan abridores, lineup o datos fiables.
Uso responsable: esto es una herramienta analítica, no una garantía. El béisbol conserva varianza extrema. Un buen modelo debe detectar oportunidades, medir incertidumbre y marcar PASS con frecuencia. Los datos de MLB se consultan al abrir el archivo; la línea del sportsbook puede capturarse manualmente o mediante una API key propia. El lineup se carga desde MLB cuando está publicado; los splits se suavizan para evitar muestras pequeñas. El bullpen se construye automáticamente desde el roster activo y uso reciente. V7.0 trabaja exclusivamente el Over/Under de juego completo: Ranking, Censo, Brier, aprendizaje y Rendimiento por equipo comparten un único objetivo. F5 y team totals quedan fuera del sistema activo. En la app completa alojada en Netlify, las líneas Total + momios se obtienen primero mediante una función del mismo sitio que consulta ESPN/DraftKings sin API key y evita bloqueos CORS; el navegador conserva ESPN y Covers como respaldos. El censo se guarda localmente, puede consultarse sin conexión y lleva W-L-Push, acierto, Brier y unidades cuando existe momio, sin mezclarse con Apuestas ni con Brier LAB.
